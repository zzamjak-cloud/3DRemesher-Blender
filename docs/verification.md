# 0.3.0 검증 결과

2026-09-19, macOS의 실제 Blender 5.2.0 LTS와 Linux CI의 Blender 4.2.0·5.2.0에서 검증했습니다. 아래 모델 수치는 macOS에서 측정했습니다. 이 결과는 구현한 기능과 처리 경로의 검증이며 상용 도구 수준의 캐릭터 엣지 루프·변형 품질을 보증하지 않습니다.

## 통과한 검사

| 검사 | 결과 |
| --- | --- |
| Python 단위 테스트 | 67개 통과 |
| 프로젝트 정적 검사·버전 일치 | 통과 |
| macOS 실행기 셸 구문 | 통과 |
| `tests/blender_smoke.py` | 실제 Blender 등록·해제, 데이터 변환, 원본 보존, 오류 처리 통과 |
| `tests/blender_engine.py` | 실제 worker JSON 통신·쿼드 출력·취소·깨진 결과 파일 정리 통과 |
| `tests/blender_acceptance.py` | 구·큐브·토러스의 감소·대칭·밀도·가이드 통합 통과 |

| ZIP 내용과 최종 런타임 소스의 바이트 일치 | 통과 |

단위 검사에는 누적 QEM, 형상 편차로 인한 축소 제한, 밀도 분포, 특징선 모서리 보존, 다중 축 대칭과 근접한 float 좌표, 분리 표면 재투영, 먼 표면으로의 투영 방지, 방향장 정렬 개선 및 뒤집힌 쿼드 이동 거부가 포함됩니다.

개발 프로필은 `~/Library/Application Support/Blender/3DRemesherDev/5.2/`이며 임시·종료 복구 경로도 이 프로필 안으로 분리합니다. 일상 프로필에 애드온을 설치하지 않았습니다.

모든 행에서 쿼드 비율 100%, 경계·비다양체 엣지·퇴화 면 0개, 원본 데이터 보존을 확인했습니다. 대칭 결과의 대응 정점 오차는 0입니다. 밀도 검사는 Blender RGB 속성 추출과 균일 밀도 대비 고밀도 영역의 면 개수·평균 면적 변화를 함께 확인합니다.

**목표 수는 엄격한 개수 보장이 아닙니다.** 표면·특징선 보존 때문에 크게 초과할 수 있으며 표에 그 결과를 그대로 기록했습니다. 결과 정점과 면 중심의 편차가 원본 최대 축 길이의 4%를 넘으면 해상도를 보정하고, 재시도 후에도 넘으면 적용하지 않습니다. 이 샘플 검사는 전체 면의 Hausdorff 거리나 자기교차 부재를 보증하지 않습니다. 최대 종횡비가 큰 면도 있을 수 있으므로 실제 모델의 와이어를 확인해야 합니다.

실행별 상세 보고서는 `dist/acceptance_results.json`, GUI 결과는 `dist/gui_verification.json`에 생성됩니다. GUI 검사는 코드로 실제 모달 경로와 취소 함수를 실행했으며 물리적인 Esc 키 입력과 패널의 시각적 배치는 별도 수동 평가 대상입니다.

## 비교 데모

`dist/3DRemesher_Prototype.blend`에 원본 삼각형 1,280개와 결과 374쿼드를 나란히 저장했습니다. 목표는 256개이며 형상 보존 때문에 46.1% 초과했습니다. 최대 표면 편차 0.027183, 평균 0.007515, 최대 종횡비 4.622, 평균 1.395입니다. 경계·비다양체 엣지·퇴화 면은 모두 0입니다.

데모 생성 프로세스는 종료 코드 0이지만 Blender 종료 시 약 0.023 MB의 미해제 메모리 진단이 나왔습니다. 원인은 분리하지 않았습니다.

재빌드 시 ZIP 메타데이터 때문에 해시가 달라질 수 있습니다.

## 배포 검증

Linux CI에서는 Blender 4.2.0과 5.2.0으로 등록·worker·수용 검사를 실행합니다. 릴리스는 해당 검사를 통과한 ZIP을 게시하며, Pages 인덱스의 크기와 SHA-256을 ZIP과 대조합니다. [Actions 실행 결과](https://github.com/zzamjak-cloud/3DRemesher-Blender/actions)와 [배포 인수 절차](distribution.md)에서 확인할 수 있습니다.

배포 인수 스크립트는 일상 프로필과 분리한 새 프로필에서 원격 신규 설치 및 0.2.0 → 0.3.0 업데이트를 실행합니다. 설치 버전·활성화·시작 시 업데이트 확인 설정·worker·64쿼드 생성·원본 보존 결과를 `dist/distribution-verification.json`에 기록합니다.

## 미검증 범위

- Windows 런타임. Windows 실행기는 BOM, 인자 전달, Junction 보호와 종료 코드 전달을 정적으로 검사했습니다.
- 사용자 제공 캐릭터의 눈·입·관절 루프와 실제 리깅·애니메이션 품질.
- 대형 스캔 입력의 실용적인 처리 시간. 선언된 입력·출력 상한은 성능 보장이 아닙니다.
- 일상 사용자 프로필은 변경하지 않았습니다. 원격 설치·업데이트 인수 검사는 별도 프로필을 사용합니다.

UV·스킨 웨이트·셰이프 키 전송, NURBS 가이드, 모디파이어 평가 결과의 리메시는 이번 구현 범위에 포함하지 않습니다.
