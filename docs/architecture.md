# 적응형 리토폴로지 엔진

## 처리 순서

1. **입력 검증과 정규화**: 원본을 복사한 불변 데이터로 처리합니다. 중복·퇴화 면, 방향 불일치, 비다양체 엣지와 bowtie 정점을 거부하고 크기를 정규화합니다.
2. **특징선과 삼각 표면**: 경계, sharp/seam과 면 사이 각도로 특징선을 정합니다. 오목 다각형은 방향을 보존하는 귀 자르기로 삼각화합니다.
3. **대칭 기준 영역**: 선택한 X/Y/Z의 양의 영역을 로컬 원점 기준으로 절단합니다. 교점의 밀도를 보간하고 중앙 경계에 제약을 겁니다. 전체가 대칭 평면에 놓인 면은 중복 복제하지 않습니다.
4. **적응형 재표본화**: 원본 면의 평면 quadric을 정점에 누적하고, 엣지 위의 오차 최소점·끝점·중점을 비교하여 축소 위치를 정합니다. 누적 오차와 밀도로 비용을 정하고, 원본 표면에 대한 새 면 중심·엣지 중점의 거리도 검사합니다. 고밀도 영역은 전체 평균 밀도에 비례해 허용 표면 편차를 좁혀 세부 면을 남깁니다. 저밀도 영역의 기존 표면 편차 상한은 완화하지 않습니다. 목표 수에 도달하지 못해도 현재 면 수를 유지하는 재분배를 시도합니다. 면을 늘릴 때는 밀도와 길이를 기준으로 공유 엣지를 분할합니다. 링크 조건·면 방향·특징선을 보호합니다. 특징선의 모서리와 분기점은 고정하고, 완만한 두 갈래 특징선은 같은 선 위에서만 축소합니다. 밀도 대비는 밝기 값에 적용하는 지수이며 값 0은 작은 양의 하한으로 처리합니다. 거의 동일한 축소 비용은 메시 크기와 평균 밀도에 비례하는 허용 범위에서 엣지 번호로 정렬합니다.
5. **4방향장**: 특징선, 인접 면의 법선 변화와 가이드 접선을 면별 접평면의 방향 제약으로 사용합니다. 복소수 4승 표현으로 90도 동치를 처리하고 이웃 면에 방향을 반복 전파합니다. 특징선을 가로질러 방향을 평균하지 않습니다.
6. **쿼드 추출과 목표 보정**: 볼록성과 형상 품질·방향장 정렬로 인접 삼각형을 묶고, 짧은 교대 경로로 짝지음을 보완합니다. 모든 패치가 쿼드이면 직접 출력 후보로 사용하고, 나머지는 패치 중심과 공유 엣지 중점을 연결해 순수 쿼드를 만듭니다. 측정한 결과 개수에 따라 삼각형 예산을 직접 출력과 분할 출력의 인접 예산을 최대 네 번 시도하고 가장 가까운 결과를 선택합니다.
7. **정점 정렬과 재투영**: 축소 직후에도 한 차례 표면 재투영을 수행하여 쿼드 생성의 기준 정점을 보정합니다. 특징선·경계를 고정한 채 내부 정점을 방향장에 맞춰 이동합니다. 원본 컴포넌트 대응과 법선 방향을 제한한 삼각 표면 BVH의 최근접점으로 재투영하며 국소 면 뒤집힘과 과도한 면적 감소를 검사합니다.
8. **미러와 최종 검사**: 원본 정점 ID와 반사 조합으로 대칭 경계만 연결합니다. 서로 분리된 컴포넌트를 위치만으로 합치지 않습니다. 최종 쿼드 비율·연결성·면 방향과 개수·표면 편차를 보고합니다. 결과 정점·면 중심의 최대 표면 편차가 원본 최대 축 길이의 4%를 넘으면 해상도를 두 배씩 최대 두 번 재시도합니다. 이후에도 넘으면 결과를 적용하지 않습니다. 이 보정으로 목표 개수보다 결과가 많아질 수 있으며 실제 오차율을 보고합니다.

## 모듈

| 파일 | 역할 |
| --- | --- |
| `core.py` | Blender와 독립적인 입력·결과 계약 |
| `engine.py` | 검증, 예산 피드백, 쿼드 추출, 전체 처리 순서 |
| `adaptive.py` | 국소 표면오차 기반 엣지 축소·분할, 밀도 재분포 |
| `symmetry.py` | 축 절단·밀도 보간·정확한 미러 연결 |
| `field.py` | 4방향장과 정점 정렬 |
| `surface.py` | 삼각 표면 BVH, 최근접점 |
| `blender_adapter.py` | 메시·가이드·RGB 휘도 밀도 변환 및 새 오브젝트 생성 |
| `operators.py` / `worker.py` | UI 생명주기와 분리 프로세스 실행 |

외부 엔진, Blender Remesh/QuadriFlow, 외부 Python 패키지를 사용하지 않습니다. 감소는 누적 QEM을 사용하는 엣지 제한 축소입니다. 3차원 임의 위치로 이동하는 전역 최적화와는 구현 범위가 다릅니다. 방향장과 쿼드 추출도 정수 격자 파라미터화 구현은 아닙니다.

## 품질 지표 해석

- `target_error_ratio`: 목표 대비 실제 개수 차이의 절댓값 비율. 특징선·대칭 배수·위상 제약 때문에 0이 아닐 수 있습니다.
- `max_surface_error` / `mean_surface_error`: 결과 정점과 면 중심에서 원본 삼각 표면까지의 최근접 거리. 오브젝트 로컬 단위이며 대칭에서는 유지한 양의 영역을 기준으로 측정합니다. 양방향 Hausdorff 거리나 면 전체 오차 상한이 아닙니다.
- `symmetry_error`: 반사한 정점의 대응 좌표 오차. 강제 대칭 결과는 정확하게 대응하도록 구성합니다.
- `field_alignment`: 결과 엣지가 방향장에 얼마나 정렬되는지 0~1로 측정한 평균값. 해부학적 루프의 적합도는 아닙니다.
- `max_aspect_ratio` / `mean_aspect_ratio`: 쿼드의 최장·최단 엣지 길이 비율.

면 개수나 쿼드 비율만으로 게임용 품질을 판단하지 않습니다. 눈·입·관절의 루프와 특이점 배치는 실제 모델의 변형으로 검토해야 하며 수동 수정이 필요할 수 있습니다.

## Blender 실행

GUI 연산자는 Blender 번들 Python으로 `worker.py`를 실행하고 JSON으로 입력·진행률·결과를 교환합니다. Blender 데이터 생성은 메인 스레드에서만 수행합니다. 취소, 파일 로드 및 애드온 해제 시 프로세스와 임시 파일을 정리합니다. 적용 전 원본과 사용한 입력의 변경을 확인합니다. 백그라운드 연산자는 동기 실행이며, 통합 검사에서는 실제 worker 경로도 별도로 검증합니다.

[Blender의 스레딩 제한](https://docs.blender.org/api/main/info_gotchas_threading.html)에 따라 장기간 실행하는 Python 스레드를 사용하지 않습니다.

## 입력 범위와 남은 품질 한계

입력 정점 20,000개, 면 10,000개, 전체 면 코너 50,000개, 단일 면 정점 256개, 가이드 선분 20,000개를 제한합니다. 삼각화된 소스는 20,000삼각형, 최종 출력은 200,000쿼드까지 허용합니다. 상한은 검증한 실용 성능을 뜻하지 않습니다. 현재 엔진은 Python으로 작성되어 대규모 스캔 처리에는 추가 최적화가 필요합니다.

원본 모디파이어 평가, UV·웨이트·셰이프 키 전송, NURBS 가이드는 포함하지 않습니다. 단위 테스트와 Blender 수용 검사는 별도의 검증 문서에 기록합니다.
